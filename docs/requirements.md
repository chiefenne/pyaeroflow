# PyAeroFlow – Requirements

Living document, updated after each requirement step.

- **D** – decided
- **L** – planned for later (decided, not in the first stages)
- **P** – possible later (mentioned, not decided)
- **X** – not planned
- **O** – open requirement step, with the current proposal

Status: 2026-10-13, requirements complete (steps 1–13). Implementation follows the stage plan (section 7).


## 1. Purpose and scope

- 2D Navier–Stokes / RANS solver for airfoil aerodynamics, companion to
  [PyAero](https://github.com/chiefenne/PyAero).
- Developed as a standalone code first; integration with PyAero later (L4).
- Numerics based on [SU2](https://github.com/su2code/SU2), unless newer,
  demonstrably better algorithms exist.
- Verified against analytic solutions and published numerical and experimental
  reference data for a small set of test cases (D40).
- Software engineering lean but solid: package structure, tests including
  reference solutions, run locally (no CI, X5).
- Step-by-step development; every stage ends with results that can be tested.

Practice of SU2/FUN3D for the turbulence variable | The line search and acceptance use the plain RMS, in which ν̃ is 0.4–3 %, so a step that multiplies ν̃ in a few boundary-layer cells passes unseen. ## 6. Open requirement steps

None. New requirements arising during implementation are added here first.

Notes from implementation:

- Stage 3: the last plate face next to a pressure outlet shows a local C_f
  deviation (+8 % on the coarse Blasius mesh, one face only); comparisons
  exclude the outlet corner. The cell next to the corner takes its pressure
  from the outlet face and its velocity from the wall face in the
  least-squares stencil.
- Stage 6, PyAero meshes (boundaries airfoil/inlet/outlet/top/bottom): read
  and run without changes (PyAero's names are mapped to types in the case
  file, identical farfield boundaries count as one freestream). First mesh
  (52k cells, farfield 3.5 chords, first cell 4·10⁻³ chords): y⁺ ≈ 900 at
  Re 6·10⁶, Euler lift −6.4 % vs 500 chords, −2.9 % with the vortex
  correction. Second mesh (`examples/meshes/naca0012_pyaero_100k.su2`, 100k
  cells, farfield 5 chords, outlet 25 chords, first cell 1·10⁻⁴ chords):
  y⁺ = 12–17 at Re 6·10⁶ (0.5–2.5 at Re 2·10⁵–10⁶, its proper range); SA
  at Re 6·10⁶, α = 10°, vortex correction: C_L = 1.016 (−6.9 %), C_D =
  0.0192 with the viscous part 0.0036 (TMR 0.0062): at y⁺ ≈ 12 the
  wall shear is underpredicted by 40 % and the boundary layer too thick —
  the TMR case needs a first cell of about 5·10⁻⁶ chords (y⁺ =
  y₁ Re √(C_f/2) with C_f ≈ 0.003), 60–80 layers at growth ≈ 1.15. The
  run converged four orders in 45 iterations (7 s per iteration, 100k
  cells, 2 cores) and then stalled with rejected Newton steps (GMRES not
  converging at the tolerance) — open, see P14. The refined wake block is
  aligned with the chord; at 10° the wake leaves it after one to two chords,
  which is acceptable (the wake is thin only near the trailing edge).
- Stage 6: on the airfoil O-grid the approximate-Jacobian iteration stalls
  one to two orders below the start (first-order Jacobian vs second-order
  residual) and the Newton–Krylov switch needs the iteration criterion
  (`switch_at_iteration = 40`); with the limiter frozen there, 33k cells
  converge seven orders in 32–53 iterations (125–175 s on 2 cores). On the
  512×256 grid (131k cells, 4 variables) the approximate-Jacobian phase did
  not reduce the residual (CFL stayed at 30–50) and Newton–Krylov made slow
  progress before the run budget ended: 18.6 s per approximate-Jacobian
  iteration (Jacobian assembly plus SuperLU on 524k unknowns) and 30 s per
  Newton–Krylov iteration (10 GMRES iterations). This is the stage-6 data
  point of the large-mesh profiling pass (D52): the direct factorization
  dominates and a stronger start-up strategy (lower starting CFL, first-order
  iterations, continuation in α) and a cheaper preconditioner (P13) are the
  next steps for 100k+ cells.
- Stage 5: the SA source and its AD derivative must stay finite where both
  ν̃ and the vorticity vanish (r = ν̃/(S̃κ²d²) is 0/0 there): the unused
  branches of `jnp.where` are kept finite and the r denominator is floored
  relative to ν (an absolute 1e-300 floor underflowed in the derivative and
  gave NaN Jacobians). The wall distance is the exact point-segment distance
  to the candidate faces from a KD-tree over face midpoints and nodes.
- Stage 4: the inner residual drop of a time step is measured against the
  unsteady residual of the previous solution R*(uⁿ), not against the
  residual of the extrapolated start 2uⁿ − uⁿ⁻¹ (which is smaller and would
  demand more accuracy than intended). The physical time term stabilises the
  inner system, so the inner pseudo-time CFL starts at 1e4 and Newton–Krylov
  is used from the first inner iteration: smooth cases need 1–2 inner
  iterations per step, the DFG 2D-2 shedding 1.3–2. Temporal-order studies
  need a tight inner convergence (6 orders); with 4 orders the error at the
  smallest Δt is polluted by the inner iteration error (observed order 1.4
  instead of 2.1 on the last level).
