# Example meshes

SU2 meshes (`.su2`) of the validation cases. Meshes of the other example
cases (channel, cavity, cylinder, plates) are generated by
`examples/cases/make_meshes.py` and `examples/cases/make_plate_lm.py` and are
not committed.

| file | cells | made with | boundary faces | used by |
|---|---|---|---|---|
| `naca0012_pyaero_100k_y1.su2` | 100k | PyAero, C-mesh, 113 points per side, first cell 5·10⁻⁶ c | airfoil, inlet, outlet, top, bottom | `naca0012_pyaero_*.toml`, validation §6 |
| `naca0012_pyaero_150k_y1.su2` | 149k | PyAero, 25-chord tunnel | same | `naca0012_pyaero_rans_far.toml` |
| `naca0012_pyaero_300k_y1_s450.su2` | 295k | PyAero, 472 points per side | same | `naca0012_pyaero_rans_fine.toml` |
| `naca0012_ogrid_256x128.su2` | 33k | `pyaeroflow.mesh.naca0012_ogrid(256, 128, reynolds=6e6)`, farfield 500 chords | airfoil, farfield | `naca0012_rans.toml`, `stage6_naca0012.py` |
| `e387_pyaero_y1.su2` | 209k | PyAero, C-mesh, 481 points per side, first cell 2·10⁻⁴ c | airfoil, inlet, outlet, top, bottom | `e387_transition.toml`, `e387_aft.toml`, validation §7, §8 |
| `sd7003_C10_W25_320k_cells.su2` | 320 600 | PyAero, C-mesh, sharp trailing edge | airfoil, inlet, outlet, top, bottom | `aft_sd7003*.toml`, `sst_sd7003.toml`, `lm_sd7003*.toml`, validation §9, §10 (the mesh of the main validation runs) |
| `sd7003_C10_W25_320k_cells_blunt_TE.su2` | 326 580 | same, trailing edge 0.3 % chord thick | same | `aft_sd7003_tu05_blunt.toml`, validation §9 |
| `sd7003_ogrid_39k.su2` | 38 880 | `make_sd7003_ogrid.py` from the wall contour of an SA-AFT α = 4° run, farfield 100 chords | airfoil, farfield | `sst_sd7003_ogrid.toml`, validation §9, §10 |
| `RAE2822_C10_W25_320k_cells.su2` | 320 600 | PyAero, C-mesh, RAE 2822 | **Airfoil, Inlet, Outlet, Top, Bottom** (capitalised) | not used yet (kept for a later transonic solver, L1) |

In the PyAero names `C10` is the tunnel height of 10 chords above and below
the airfoil and `W25` the wake length of 25 chords behind the trailing edge.
The chord is 1. The PyAero meshes are not scaled for a Reynolds number; check
y⁺ with `pyaeroflow check-mesh MESH --re R`. The RAE 2822 mesh has capitalised
boundary names: use them in the `[boundary.<name>]` sections of a case file.

`make_sd7003_ogrid.py` needs the wall CSV of a run on the SD7003 C-mesh
(`python make_sd7003_ogrid.py WALL.csv OUT.su2 [n_surface] [n_radial]`); the
committed O-grid is the result.
